# 影像裁切與自訂形狀設計規格

日期：2026-08-22

## 目標與背景

NexaForge 現有影像工具已支援縮放、壓縮、格式轉換與 EXIF 處理，但缺少可直接調整取景並輸出造型素材的裁切工具。本功能新增一個完全在瀏覽器本機執行的「影像裁切」工具，讓使用者上傳 JPG、PNG 或 WebP 後，以矩形、圓形、心形、星形、多邊形或自由手繪路徑裁切圖片，先確認即時預覽，再下載結果。

主要使用者是需要快速製作頭像、貼圖或造型素材的人。成功條件是預覽與下載結果一致、操作可復原，且圖片不離開裝置。錯誤成本主要來自取景偏移、遮罩與輸出不一致、透明區域被錯誤填色，或在編輯失敗後遺失工作。

## 範圍

### 包含

- 新增 `/image/crop` 影像工具頁與影像分類入口。
- 支援單張 JPG、PNG 或 WebP 圖片。
- 支援矩形、圓形、心形、星形、多邊形與自由手繪形狀。
- 圖片拖曳定位與縮放控制。
- 預設形狀尺寸調整；矩形可獨立調整寬、高，圓形維持 1:1，心形與星形等比例縮放。
- 多邊形節點新增、移動、刪除與閉合。
- 自由手繪路徑自動閉合、簡化及轉為可編輯節點。
- 即時遮罩預覽、復原上一步、重設與最終結果預覽。
- 矩形輸出可選 JPG、PNG 或 WebP；所有非矩形輸出透明 PNG。
- 中英文文案、錯誤狀態、鍵盤操作與響應式版面。

### 不包含

- 圖片旋轉、翻轉、濾鏡、文字或貼圖編輯。
- 多張圖片批次裁切。
- 專案儲存、跨頁恢復、雲端同步或伺服器上傳。
- 羽化邊緣、布林形狀運算或多個獨立遮罩區域。
- 第三方圖片編輯器套件。

## 架構決策

採用單一 Canvas 幾何模型。編輯預覽與最終輸出共用同一組標準化路徑、圖片變換與座標轉換函式，避免 SVG 預覽與 Canvas 輸出之間出現偏移。

曾考慮的替代方案：

1. SVG 編輯、Canvas 輸出：節點顯示方便，但需要維護兩套座標轉換，縮放後的預覽與輸出較容易不一致。
2. 第三方編輯器：可縮短基本裁切的開發時間，但任意遮罩、自由手繪與現有版型仍需大量客製，並增加依賴與維護成本。

選定 Canvas 模型的原因是功能需完全本機執行、形狀種類多，而且預覽正確性比快速引入通用編輯器更重要。

## 元件與責任

### `ImageCropPage`

- 組合 `ToolPageTemplate`、檔案上傳、編輯器、輸出選項、處理狀態與下載。
- 管理目前檔案、裁切設定、處理結果及使用者可見錯誤。
- 驗證 MIME、檔案大小及形狀有效性。
- 追蹤工具開啟、處理開始、成功、失敗與下載事件。

### `ImageCropEditor`

- 解碼並顯示來源圖片。
- 顯示遮罩外的半透明暗色區域與保留區域。
- 處理圖片拖曳、縮放、預設形狀尺寸控制、多邊形與自由手繪輸入。
- 提供復原、重設、節點座標編輯與鍵盤操作。
- 透過明確的 props 接收與回傳編輯狀態，不負責產生下載 Blob。

### `cropGeometry`

- 定義標準化的形狀與座標資料。
- 建立矩形、圓形、心形及星形路徑。
- 驗證與閉合多邊形。
- 簡化自由手繪取樣點，並保留足以維持輪廓的節點。
- 計算形狀的緊密邊界。
- 將預覽座標轉換為原始圖片像素座標。
- 為預覽及輸出建立相同的 Canvas 路徑。

### `cropImage`

- 使用 `createImageBitmap` 解碼來源圖片。
- 依原始圖片解析度、圖片變換及形狀路徑計算輸出畫布。
- 先將輸出畫布清為透明，再套用遮罩並繪製圖片。
- 矩形依使用者格式輸出；非矩形強制使用 `image/png`。
- 回傳 `FileProcessResult`，並確保釋放 `ImageBitmap`。

## 資料模型

所有幾何座標以編輯器內容區的標準化座標表示，X 與 Y 的有效範圍是 0 到 1。圖片變換與形狀資料分開保存，讓移動圖片不會修改遮罩，調整遮罩也不會改寫圖片本身。

```ts
type CropShapeKind =
  | "rectangle"
  | "circle"
  | "heart"
  | "star"
  | "polygon"
  | "freehand";

interface CropPoint {
  x: number;
  y: number;
}

interface ImageTransform {
  offsetX: number;
  offsetY: number;
  scale: number;
}

interface CropShape {
  kind: CropShapeKind;
  bounds?: { x: number; y: number; width: number; height: number };
  points?: CropPoint[];
}

interface CropSettings {
  shape: CropShape;
  imageTransform: ImageTransform;
  format: "jpeg" | "png" | "webp";
  quality: number;
}
```

`bounds` 用於矩形、圓形、心形與星形；`points` 用於多邊形與自由手繪。自由手繪完成後仍保留 `kind: "freehand"`，但其簡化後節點可透過與多邊形相同的節點編輯介面修正。

## 操作流程

1. 使用者從影像分類進入「影像裁切」。
2. 使用者拖放或選擇單張 JPG、PNG 或 WebP。
3. 系統解碼圖片並進入編輯狀態，預設為覆蓋圖片中央主要區域的矩形。
4. 使用者拖曳圖片調整位置，或用縮放滑桿改變取景。
5. 使用者選擇形狀：
   - 預設形狀立即顯示對應遮罩與尺寸控制點。
   - 多邊形逐點加入節點；至少三點後可閉合。
   - 自由手繪在放開指標時自動閉合、平滑並簡化為節點。
6. 系統即時將遮罩外區域變暗，保持區域顯示原圖。
7. 使用者可復原最近一次編輯或重設整個取景。
8. 有效形狀成立後，使用者按下「裁切圖片」。
9. 系統以原始圖片像素重建相同遮罩，輸出緊貼形狀外框的圖片。
10. 結果區顯示實際輸出 Blob 的預覽、尺寸資訊與下載按鈕。

## 形狀規則

- 矩形：四邊可調整，最小寬、高各為編輯區的 5%。
- 圓形：外框保持 1:1，可等比例縮放。
- 心形與星形：保持 1:1，可等比例縮放；星形固定為五角星。
- 多邊形：至少三個互不重疊的有效節點；以點擊第一點或「閉合形狀」完成。
- 多邊形線段不可自我交叉；發生交叉時保持編輯狀態並指出需調整的節點。
- 自由手繪：指標移動至少 2 個預覽像素才取樣一次，放開後首尾自動閉合，再以編輯區對角線 0.3% 為容差簡化；簡化後至少保留三點、最多保留 500 點。
- 所有形狀的最終邊界必須與圖片有交集；完全位於圖片外時不可處理。
- 形狀可超出圖片顯示範圍，但超出部分在輸出中保持透明；介面需提示透明區域，而不是阻止使用者繼續。

## 版面與響應式行為

- 桌面將工具頁主要區域調整為約 70/30：左側為上傳與畫布，右側為形狀、縮放、格式與操作控制。
- 編輯畫布寬度流動，最大使用可用工作區；顯示區保持正方形並以 `contain` 起始縮放圖片。
- 形狀控制依「預設、多邊形、自由手繪」分組，群組內使用具文字名稱的按鈕。
- 主要動作「裁切圖片」位於會影響結果的控制之後，局部只有一個主要強調動作。
- 畫面變窄導致控制區文字換行或畫布不足時改為單欄，順序為上傳、畫布、形狀控制、輸出控制。
- 手機保留縮放滑桿與方向控制，不要求雙指縮放才能完成工作。
- 使用現有色彩、間距、圓角、焦點環與按鈕 token，不引入新的視覺系統。

## 無障礙與輸入方式

- Canvas 提供可理解的名稱與目前形狀描述；關鍵狀態亦以文字顯示，不只依賴 Canvas 圖像。
- 形狀按鈕使用 `aria-pressed` 或等價的選取語意，並包含文字標籤。
- 預設形狀與圖片位置可用方向鍵微調；按住 Shift 時使用較大步距。
- 縮放使用原生 range 控制，並顯示數值。
- 多邊形與自由手繪節點可取得鍵盤焦點；方向鍵移動，Delete 刪除。
- 畫布下方提供節點座標清單，支援以百分比欄位新增與編輯節點，作為自由繪製的鍵盤替代方式。
- 錯誤與受影響的控制建立可程式判讀的關聯，並以 `role="alert"` 或狀態區宣布。
- 可操作目標沿用現有最小尺寸與可見焦點樣式；不以顏色作為唯一狀態訊號。
- 響應式重排不改變 DOM 閱讀順序。

## 狀態與錯誤處理

| 狀態 | 畫面與可用操作 | 復原方式 |
|---|---|---|
| 未上傳 | 顯示上傳區，不顯示空白畫布 | 選擇有效圖片 |
| 圖片載入中 | 保留穩定畫布區並顯示解碼中狀態 | 解碼失敗時更換檔案或重試 |
| 編輯中 | 即時顯示遮罩；可切換形狀、復原與重設 | 復原上一步或重設 |
| 形狀無效 | 停用裁切並在相關控制旁說明原因 | 補足、閉合或移動節點 |
| 處理中 | 鎖定裁切與下載；保留目前預覽 | 等待完成；失敗後重試 |
| 處理失敗 | 保留檔案、形狀、圖片位置及縮放 | 直接重試或調整後再處理 |
| 處理成功 | 顯示實際 Blob 預覽、尺寸與下載 | 返回編輯、再次處理或更換檔案 |

拒絕無效 MIME、超過既有檔案大小限制的檔案、無法解碼的圖片、零尺寸圖片及 Canvas 無法建立或序列化的情況。更換、清除圖片或卸載頁面時撤銷舊的 Object URL。錯誤訊息使用既有翻譯與錯誤樣式，並在能修正問題的區域附近顯示。

## 輸出規則

- 輸出尺寸使用原始圖片解析度與目前圖片變換計算，不受 CSS 預覽尺寸影響。
- 輸出畫布緊貼形狀的軸向邊界框。
- 矩形可選 JPG、PNG 或 WebP，品質值沿用現有影像工具的 1–100 控制。
- 圓形、心形、星形、多邊形與自由手繪固定輸出 PNG，遮罩外像素的 Alpha 為 0。
- 非矩形模式隱藏或停用不適用的格式選擇，並清楚顯示「透明 PNG」。
- 品質控制只在 JPG 或 WebP 有效時顯示；PNG 不顯示無效的品質選項。
- 若矩形範圍包含來源圖片外部區域，PNG 與 WebP 保留透明像素；JPG 以白色填補，且編輯預覽在選擇 JPG 時同步顯示白色填補效果。
- 下載檔名保留來源基底名稱並加上 `-cropped`，副檔名符合實際 MIME，例如 `avatar-cropped.png`。

## 測試策略

採測試驅動開發，每一項行為先建立會因功能尚未存在而失敗的測試，再加入最小實作。

### 幾何單元測試

- 標準化座標與預覽／原圖像素轉換。
- 矩形、圓形、心形與五角星路徑邊界。
- 多邊形少於三點時無效，三點以上可閉合。
- 自我交叉的多邊形無效並回報可修正原因。
- 自由手繪取樣簡化後仍保持閉合且至少三點。
- 緊密邊界與形狀超出圖片時的透明範圍。
- 圖片拖曳及縮放後，預覽與輸出使用相同轉換結果。

### 影像服務測試

- 矩形依指定格式與品質輸出。
- 非矩形忽略其他格式並輸出透明 PNG。
- 矩形超出來源圖片時，PNG/WebP 保留透明像素，JPG 使用白色填補。
- 輸出尺寸等於形狀的原圖像素邊界。
- 檔名包含 `-cropped` 且副檔名正確。
- Canvas context 或 Blob 建立失敗時回報錯誤並釋放 ImageBitmap。

### 元件與頁面測試

- 選擇有效圖片後顯示編輯器預覽。
- 切換各形狀時更新選取狀態與輸出格式提示。
- 多邊形不足三點或未閉合時不可裁切並顯示原因。
- 自由手繪完成後產生可編輯節點。
- 復原與重設回復預期狀態。
- 節點可經鍵盤移動、刪除並透過座標欄位新增。
- 處理期間裁切按鈕具 busy 狀態。
- 處理失敗保留編輯內容並提供重試。
- 清除或更換圖片會撤銷舊預覽 URL。

### 整合與實際操作驗證

- `/image/crop` 路由、影像分類入口、首頁搜尋、相關工具與最近使用工具皆能辨識新工具。
- 中英文標題、說明、操作、錯誤、教學及 FAQ 文案完整。
- 執行完整 Vitest 測試與 TypeScript/Vite 建置。
- 在桌面與窄螢幕實際操作矩形、預設非矩形、多邊形及自由手繪流程。
- 比對編輯器遮罩、結果預覽與下載圖片的形狀、取景、透明區域及尺寸。
- 驗證鍵盤焦點順序、方向鍵微調、節點刪除、錯誤宣布與 200% 縮放重排。

## 預計修改範圍

- 新增裁切頁、編輯器、幾何模組及其測試。
- 擴充影像服務與型別。
- 新增工具定義、路由、工具視覺標記及路由測試。
- 新增中英文工具、欄位、操作、錯誤、教學及 FAQ 文案。
- 新增只套用於影像裁切頁的編輯器與響應式樣式。
- 視測試需要補充 Canvas、ImageBitmap 與 Object URL 的測試工具。

## 驗收條件

1. 使用者能上傳 JPG、PNG 或 WebP 並立即看到可操作的裁切預覽。
2. 矩形、圓形、心形、五角星、多邊形與自由手繪皆可完成裁切。
3. 多邊形與自由手繪節點可經指標及鍵盤修正。
4. 圖片可拖曳、以滑桿縮放，且可復原或重設。
5. 最終輸出取景與編輯器預覽一致，並以原始圖片解析度計算。
6. 非矩形輸出是圓外或形狀外透明的 PNG；矩形可選 JPG、PNG 或 WebP。
7. 無效形狀、解碼與處理錯誤不會清除使用者的有效編輯狀態。
8. 工具可從影像分類、搜尋與直接路由進入，並提供完整中英文內容。
9. 完整測試及正式建置通過，桌面、窄螢幕與鍵盤操作驗證沒有阻斷問題。
